# Contributing

Preserva el invariante central: el revisor permanece independiente del contexto de implementación.

1. Describe el riesgo o fallo reproducible en una issue.
2. Mantén cada skill acotada.
3. Versiona los contratos cuando cambie interoperabilidad.
4. Valida YAML, JSON y correspondencia entre carpeta y nombre.
5. No debilites production-deny ni los requisitos de evidencia sin una política versionada.
