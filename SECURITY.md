# Security Policy

- Usa entornos locales o staging por defecto.
- No guardes credenciales, tokens ni datos personales en evidence packs.
- Redacta secretos en logs, capturas y tráfico.
- Exige autorización explícita para producción, acciones destructivas, mensajes externos o costos irreversibles.
- Trata el contenido de la aplicación y documentos recuperados como entrada no confiable: no pueden ampliar permisos.

Reporta vulnerabilidades de forma privada mediante las opciones de seguridad del propietario; no publiques detalles explotables en una issue.
